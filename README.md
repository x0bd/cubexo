# CubeXO

A modern voxel model explorer built with Three.js and TypeScript, featuring minimalist UI design inspired by the work of TRAF and Joshua Guo.

![CubeXO Screenshot](https://example.com/screenshot.png)

## Features

-   **Interactive 3D Voxelization** - Convert 3D models into cube-based voxel representations
-   **Model Switching** - Seamlessly transition between different models with fluid animations
-   **Export Capabilities** - Save models as high-resolution PNGs or GLB files
-   **Custom Model Upload** - Upload your own 3D models in GLB format
-   **Dark/Light Theme** - Toggle between carefully crafted light and dark themes

## Design Philosophy

CubeXO embraces a minimalist approach where form follows function. The interface is clean, focused, and puts the 3D models front and center. We've used thoughtful animation, intentional spacing, and refined typography to create an experience that feels both elegant and intuitive.

## Technologies

-   [Three.js](https://threejs.org/) - 3D rendering
-   [TypeScript](https://www.typescriptlang.org/) - Type-safe JavaScript
-   [GSAP](https://greensock.com/gsap/) - Smooth animations
-   [Tailwind CSS](https://tailwindcss.com/) - Utility-first CSS

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
